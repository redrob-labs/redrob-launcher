Redrob Launcher portable mode

While this file sits next to redrob-launcher.exe, Redrob Launcher keeps its settings, its
download cache and its record of installed apps in the RedrobLauncherData folder beside it, and
writes nothing to %APPDATA%. Copy the whole folder to move Redrob Launcher with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\Redrob Launcher) instead.
If RedrobLauncherData can't be written (for example on a read-only drive), Redrob Launcher says
so and uses %APPDATA%\Redrob Launcher instead.
